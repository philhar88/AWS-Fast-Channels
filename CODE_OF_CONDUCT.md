# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good intent, and keep discussions about the work.

Report unacceptable behaviour privately to the maintainer through a
[GitHub private vulnerability report](https://github.com/philhar88/AWS-Fast-Channels/security/advisories/new)
marked "Code of conduct". Reports are handled confidentially.
